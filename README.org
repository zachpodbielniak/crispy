* Crispy
*Crispy Really Is Super Powerful Yo*

A GLib-native C scripting tool. Write C scripts that compile on-the-fly, cache automatically, and run with full access to GLib, GObject, GIO, and GModule.

** Features
- *Instant startup* -- compiled scripts are cached by content hash; subsequent runs load the cached =.so= directly
- *GLib-native* -- scripts link against glib-2.0, gobject-2.0, gio-2.0, and gmodule-2.0 by default
- *CRISPY_PARAMS* -- add extra compiler flags via =#define CRISPY_PARAMS= with shell expansion (backticks, =$()=)
- *CRISPY_USE* -- declare pkg-config dependencies by name and let crispy resolve the flags
- *Multiple modes* -- file, inline (=-i=), stdin (=-=), and shebang (=#!/usr/bin/crispy=)
- *Subcommands* -- =new= to scaffold, =lint= to check, =test= to run GTest, =install= to ship a native binary, =repl= for a C prompt
- *Watch mode* -- =-w= re-runs the script every time you save it
- *GDB and gprof* -- =--gdb= launches under a debugger; =--profile= compiles with =-pg= and prints a report
- *Configurable* -- =~/.config/crispy/config.c= is itself C, compiled and loaded to set defaults
- *Plugins* -- =.so= hooks at nine points in the pipeline, for auditing, timing, or flag injection
- *Editor support* -- =crispy-language-server= proxies clangd with crispy-aware shebang and flag handling
- *Extensible library* -- GObject interfaces for compiler, cache, and dependency-resolution backends

** Quick Start
#+begin_src sh
# Install build dependencies (Fedora 42+)
make install-deps

# Build
make

# Run an example
./build/release/crispy examples/hello.c

# Inline mode
./build/release/crispy -i 'g_print("hello\n"); return 0;'

# Make a script executable
chmod +x examples/hello.c
./examples/hello.c
#+end_src

** Script Format
#+begin_src C
#!/usr/bin/crispy
#define CRISPY_PARAMS "-lm"

#include <math.h>
#include <glib.h>

gint
main(
    gint    argc,
    gchar **argv
){
    g_print("sqrt(2) = %f\n", sqrt(2.0));
    return 0;
}
#+end_src

** Usage
#+begin_example
Usage: crispy [OPTIONS] SCRIPT [SCRIPT_ARGS...]
       crispy -i "CODE" [SCRIPT_ARGS...]
       crispy - [SCRIPT_ARGS...]

Options:
  -i, --inline CODE         Execute inline C code
  -I, --include HEADERS     Additional headers (semicolon-separated)
  -p, --preload LIBNAME     Preload a shared library
  -n, --no-cache            Force recompilation (skip cache)
  -S, --source-preserve     Keep temp source files
      --gdb                 Compile with debug symbols, launch under gdb
      --profile             Compile with -pg, run, and print a gprof report
  -w, --watch               Re-run the script when it changes
      --dry-run             Describe the compile (or the cache hit), do not run
  -P, --plugins PATHS       Load plugin .so files (colon/comma-separated)
  -c, --config PATH         Use this config file
      --no-config           Skip config loading
      --cache-dir PATH      Override the cache directory
      --generate-c-config   Print a default config to stdout and exit
      --clean-cache         Purge the cache directory and exit
  -v, --version             Show version
      --license             Show AGPLv3 license notice
  -h, --help                Show help

Subcommands:
  crispy new [--template=TEMPLATE] [--dir=DIR] NAME
  crispy install [--dir=DIR] SCRIPT.c
  crispy test SCRIPT.c
  crispy lint SCRIPT.c
  crispy repl
#+end_example

Everything after the script path goes to the script, not to crispy:

#+begin_src sh
crispy script.c -f blah    # script sees: -f blah
crispy -n script.c         # crispy gets -n; script sees no args
#+end_src

See the [[file:docs/cli.org][CLI Reference]] for every option and subcommand.

** Building
*** Dependencies
Fedora 42+:

#+begin_src sh
make install-deps
#+end_src

This installs: =gcc=, =make=, =pkgconf-pkg-config=, =glib2-devel=, =json-glib-devel=, and =readline-devel=. Ubuntu/Debian and Arch are detected as well.

The language server additionally needs =clangd= on =PATH= at runtime.

For GObject Introspection support, also install =gobject-introspection-devel=:

#+begin_src sh
make install-deps BUILD_GIR=1
#+end_src

*** Build Targets
#+begin_src sh
make                # Release build (build/release/)
make DEBUG=1        # Debug build (build/debug/)
make DEBUG=1 ASAN=1 # Debug build with AddressSanitizer
make test           # Build and run all tests
make clean          # Clean current build type
make clean-all      # Clean all build artifacts
make install        # Install to /usr/local (or PREFIX=...)
make uninstall      # Remove installed files
make help           # Show all available targets
make show-config    # Show current build configuration
#+end_src

** Architecture
Crispy is built on GObject interfaces for extensibility:

#+begin_example
CrispyCompiler      CrispyCacheProvider    CrispyDependencyResolver
  (GInterface)         (GInterface)              (GInterface)
       │                    │                         │
       ▼                    ▼                         ▼
CrispyGccCompiler   CrispyFileCache        CrispyPkgConfigResolver
     (Final)             (Final)                   (Final)
       │                    │
       └─────────┬──────────┘
                 ▼
         CrispyScript (Final)
#+end_example

- *CrispyCompiler* -- compilation contract (get_version, get_base_flags, compile_shared, compile_executable)
- *CrispyCacheProvider* -- caching contract (compute_hash, get_path, has_valid, purge)
- *CrispyDependencyResolver* -- dependency contract (resolve, is_available, get_version); backs =CRISPY_USE=
- *CrispyGccCompiler* -- gcc-based compiler implementation
- *CrispyFileCache* -- filesystem cache in =~/.cache/crispy/=
- *CrispyPkgConfigResolver* -- pkg-config dependency resolution
- *CrispyScript* -- orchestrator that ties compilation and caching together
- *CrispyPluginEngine* -- loads plugin =.so= files and dispatches hooks
- *CrispyWatcher* / *CrispyRepl* -- back =--watch= and =crispy repl=

Implement the interfaces to add custom compiler backends (clang, tcc), cache strategies (in-memory, network-shared), or dependency resolution (lockfile, vendored manifest).

** Tests
GTest, one binary per =tests/test-*.c=, all picked up by wildcard:

#+begin_src sh
make test
#+end_src

The run prints each binary and each test name, which is the list -- a table here would be a second one, and the one that used to be here had drifted to naming four binaries out of twenty.

Tests that compile C at runtime (=test-gcc-compiler=, =test-script=, =test-repl=) need gcc; =/script/profile= is skipped when gprof is absent.

** Caching
Scripts are cached by SHA256 hash of the source content + the script's directory + CRISPY_USE + CRISPY_PARAMS + compiler version. Cache location: =~/.cache/crispy/=.

An entry is used only when it is a complete loadable object, is no older than the script, and none of the headers recorded beside it has been edited since. Compiler output is staged and renamed into place, so concurrent runs and interrupted compiles cannot leave a half-written entry behind.

#+begin_src sh
# Force recompilation
crispy -n script.c

# Purge all cached artifacts
crispy --clean-cache
#+end_src
