*** crispy_compiler_compile_shared
:PROPERTIES:
:CUSTOM_ID: crispy_compiler_compile_shared
:END:
#+begin_src C
gboolean
crispy_compiler_compile_shared(CrispyCompiler  *self,
                               const gchar     *source_path,
                               const gchar     *output_path,
                               const gchar     *extra_flags,
                               GError         **error);
#+end_src

Compiles the source file to a shared object suitable for loading with =g_module_open()=.

The backend writes to a staging name in =output_path='s own directory and the finished object is renamed into place, so a process loading =output_path= sees either the previous artifact or the complete new one, never a file the linker is still writing. A failed compile leaves =output_path= untouched.

A dependency file the backend wrote beside its output is published with it, under =output_path='s name with the extension replaced by =.d=.

*Parameters:*

- =self= -- a CrispyCompiler
- =source_path= -- path to the C source file
- =output_path= -- path for the output .so file
- =extra_flags= -- (nullable) additional compiler flags from CRISPY_PARAMS
- =error= -- return location for a GError, or NULL

*Returns:* TRUE on success, FALSE on error

*** crispy_cache_provider_has_valid
:PROPERTIES:
:CUSTOM_ID: crispy_cache_provider_has_valid
:END:
#+begin_src C
gboolean
crispy_cache_provider_has_valid(CrispyCacheProvider *self,
                                const gchar         *hash,
                                const gchar         *source_path);
#+end_src

Checks if a valid cached artifact exists for the given hash.

"Valid" is more than "present". An implementation is expected to reject an entry it cannot load: a compile that was killed, or one read while it was still being written, leaves a regular file that is newer than everything and that =g_module_open()= rejects for ever. If =source_path= is provided the entry must also be no older than the source file. Headers are separate -- the source's timestamp says nothing about a header it includes -- so an implementation that records the headers an entry was built from consults that record whether or not =source_path= is given.

=CrispyFileCache= applies all three: complete ELF, mtime against the script, and the header list in =<hash>.d=.

*Parameters:*

- =self= -- a CrispyCacheProvider
- =hash= -- the hash key
- =source_path= -- (nullable) original source file path for freshness check

*Returns:* TRUE if a valid cache entry exists

#+end_src

Loads a single plugin from the given path. The plugin must export a =crispy_plugin_info= symbol. If the plugin exports a =crispy_plugin_init= function, it is called immediately.

The =.so= is opened with =G_MODULE_BIND_LOCAL=, so its symbols are
reachable through the engine's own handle and are not added to the
process-wide namespace. Two plugins export the same names -- that is
what the ABI is -- and putting both into one namespace is an ODR
violation the loaded script shares.

*Parameters:*

- =error= -- return location for a GError, or NULL

*Returns:* TRUE on success, FALSE on error
